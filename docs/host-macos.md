# Хост на macOS

macOS 13+, Apple Silicon (arm64). Захват -- ScreenCaptureKit, ввод -- CGEvent.

## Установка

Скачать `rcdesk-macos.pkg` из GitHub Releases:
<https://github.com/1ax/rcdesk/releases/latest> и открыть двойным кликом.

**Gatekeeper.** pkg не подписан Developer ID (аккаунта нет), поэтому macOS
откажется его открыть. Открыть всё равно: «Системные настройки →
Конфиденциальность и безопасность» → внизу «Всё равно открыть» (появляется
после неудачной попытки). На macOS 15 и новее правый клик → «Открыть» этот
запрет больше не обходит.

**Что делает установщик.**

- кладёт `rcdesk.app` в `/Applications` (всегда туда: пакет не
  перемещаемый, Installer не станет обновлять копии в других местах);
- у вошедшего в систему пользователя включает автозапуск при входе
  (`rcdesk-host autostart on`, LaunchAgent `~/Library/LaunchAgents/app.rcdesk.agent.plist`)
  и запускает агента -- значок rcdesk появляется в строке меню. Если при
  установке никто не вошёл, этот шаг пропускается;
- перед заменой файлов закрывает запущенного агента.

**Разрешения.** При первом сеансе macOS спросит «Запись экрана» и
«Универсальный доступ» для `rcdesk` -- разрешить в «Системные настройки →
Конфиденциальность и безопасность». Приложение подписано постоянным
самоподписанным сертификатом (требование подписи = идентификатор
`app.rcdesk.agent` + лист сертификата, а не хеш бинарника), поэтому
разрешения выдаются один раз и **переживают обновления**.

**Обновление.** Открыть новый `rcdesk-macos.pkg` поверх: файлы заменяются,
агент перезапускается, разрешения остаются.

## Удаление

Вручную:

1. выйти из агента (значок в строке меню → «Выйти из rcdesk»);
2. `/Applications/rcdesk.app/Contents/MacOS/rcdesk-host autostart off`
   (или удалить `~/Library/LaunchAgents/app.rcdesk.agent.plist`);
3. удалить `/Applications/rcdesk.app`;
4. `sudo pkgutil --forget app.rcdesk.pkg`.

**Данные остаются**: `~/Library/Application Support/rcdesk` (ключ
устройства, пароль доступа) и `~/Library/Logs/rcdesk` -- при необходимости
удалить вручную.

## Сборка локально

После `cargo build --release -p rcdesk-host` (из корня репозитория):

```
bash installer/macos/build-pkg.sh target/release 0.1.0 pkg-out
```

Без переменных окружения бинарники подписываются ad-hoc (разрешения при
обновлении сбрасываются). Для подписи сертификатом задать `MACOS_SIGN_P12`
(base64 от `.p12`) и `MACOS_SIGN_P12_PASSWORD` -- как в CI (секреты GitHub с теми
же именами); временная связка создаётся и удаляется самим скриптом.
Результат -- `pkg-out/rcdesk-macos.pkg`. Иконка `installer/macos/rcdesk.icns`
перегенерируется по инструкции в `installer/windows/make-icon.py`.
