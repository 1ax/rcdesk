# Включение компьютера по сети (Wake-on-LAN)

В «Моих компьютерах» у выключенной машины есть кнопка «Включить», если:

- rcdesk на этой машине хотя бы раз был в сети с версией 0.3.4+ — тогда сервер
  знает MAC-адрес её сетевой карты;
- сейчас в сети другой компьютер того же владельца с rcdesk 0.3.4+ в **той же
  подсети** (тот же домашний/офисный роутер) — «будильник». В режиме LAN-хаба
  годится любой хост этого хаба в той же подсети.

По кнопке сервер просит будильника отправить «волшебный пакет» на MAC-адрес
выключенной машины. Из интернета напрямую разбудить нельзя: пакет не проходит
через роутер, поэтому будит сосед. Машина загружается, служба rcdesk выходит в
сеть, кнопка меняется на «Подключиться». Обычно это 1–2 минуты (стенд Windows
10: 82 с от пакета до «В сети»).

## Windows

Нужно **проводное** подключение: по Wi-Fi выключенный ПК почти никогда не
будится. Чтобы подключаться и до входа в Windows, rcdesk должен стоять в
полном режиме (служба, установка «для всех пользователей»).

Проверка без настроек: выключите ПК через «Пуск» и посмотрите на разъём сетевой
карты или порт роутера. Горит линк (часто на 10/100 Мбит) — карта под дежурным
питанием и, скорее всего, уже ждёт пакет. Попробуйте кнопку «Включить».

Если не включается:

1. **BIOS/UEFI:** включить Wake on LAN / Power On by PCI-E / Resume by LAN;
   выключить ErP / Deep Sleep (они обесточивают карту).
2. **Драйвер сетевой карты:** Диспетчер устройств → сетевой адаптер →
   Свойства → «Дополнительно»: Wake on Magic Packet — Enabled (у Intel ещё
   «Wake on Magic Packet from power off state», у Realtek — «Shutdown
   Wake-On-LAN»). Вкладка «Управление электропитанием»: «Разрешить этому
   устройству выводить компьютер из ждущего режима».
3. **Быстрый запуск** ломает пробуждение на части драйверов: Панель
   управления → Электропитание → «Действия кнопок питания» → «Изменение
   параметров, которые сейчас недоступны» → снять «Включить быстрый запуск».

## Mac

Выключенный Mac по сети **не включается** — Apple поддерживает пробуждение
только из сна. Из сна будится, если включено пробуждение для доступа к сети:
`sudo pmset -a womp 1` (то же, что галочка в настройках энергосбережения).

Чтобы включать выключенный Mac (mini, iMac, Studio) удалённо: включить запуск
после сбоя питания (`sudo pmset -a autorestart 1`) и подключить Mac через
умную розетку — выключить и включить розетку.

## Будильник

Будильником становится любой включённый компьютер с rcdesk того же владельца в
той же подсети. Если в сети всё выключается, будильником может стать роутер
(см. ниже). Режим «только будильник» для Linux (Raspberry Pi) запланирован
отдельным слайсом. До него можно будить вручную с любой Linux-машины в сети:
`wakeonlan -i <broadcast подсети> <MAC>`.

## Устройство без rcdesk (NAS, второй ПК)

«Мои компьютеры» → «Добавить устройство по MAC»: имя, MAC-адрес (в настройках
сетевой карты устройства или в аренде DHCP роутера) и сеть. Сети берутся из
ваших компьютеров с rcdesk 0.3.4+, поэтому хотя бы один такой компьютер должен
раз побывать в этой сети. У устройства в списке есть только «Включить»:
подключиться к нему нельзя, и «В сети» оно не показывается. После нажатия
команда уходит будильникам, а включилось ли устройство, смотрите на нём самом.

## Роутер-будильник (MikroTik, OpenWrt)

«Мои компьютеры» → «Добавить роутер-будильник»: имя и сеть. Сайт один раз
покажет скрипт с токеном роутера для MikroTik (RouterOS 7) или OpenWrt
(25.12+, на старых версиях — `opkg` вместо `apk`). Скрипт вставляется в
терминал роутера: на MikroTik это скрипт `rcdesk-wake` и расписание раз в 10 с,
на OpenWrt — служба `rcdesk-wake`. Роутер раз в 10 с спрашивает у
`https://rcdesk.app/wake/poll`, кого будить, и шлёт волшебный пакет в
интерфейс локальной сети (`bridge` на MikroTik, `br-lan` на OpenWrt; если у вас
другой, поправьте его в скрипте до вставки).

Роутер в списке показан как «Роутер-будильник · в сети», если опрашивал
сервер последние 30 с. Токен даёт роутеру только одно: узнавать MAC-адреса,
которые вы попросили включить. Если токен утёк, удалите роутер в списке и
добавьте заново.

Убрать скрипт с роутера:

- MikroTik: `/system scheduler remove rcdesk-wake; /system script remove rcdesk-wake`
- OpenWrt: `/etc/init.d/rcdesk-wake disable; /etc/init.d/rcdesk-wake stop;
  rm /etc/init.d/rcdesk-wake /usr/bin/rcdesk-wake`

Журнал отправленных пакетов: MikroTik — `/log print where message~"rcdesk"`,
OpenWrt — `logread -e rcdesk`.
